# 🍖 Foodie's Restaurant Website

A modern, responsive restaurant website built with pure HTML, CSS, and JavaScript. Features a sleek dark theme with orange accents, showcasing delicious grilled food specialties.

🔗 **Live Demo**: [https://ahmedshawky10001-svg.github.io/Foodie-s/](https://ahmedshawky10001-svg.github.io/Foodie-s/)

---

## 🌟 Features

- **Responsive Design** - Works perfectly on all devices (desktop, tablet, mobile)
- **Modern UI/UX** - Dark theme with orange (#ff9800) accent colors
- **Smooth Animations** - CSS animations for food images and hover effects
- **Mobile Navigation** - Hamburger menu for mobile devices
- **Video Section** - Embedded promotional video
- **Contact Form** - Functional contact form with validation
- **Google Maps** - Integrated location map
- **Social Links** - Facebook, WhatsApp, Instagram integration

## 📁 Project Structure

```
Foodie-s/
├── pages/
│   ├── index.html          # Home page
│   ├── Menu.html           # Food menu
│   ├── About.html          # About us & team
│   └── Contact.html        # Contact form & map
├── css/
│   ├── navbar.css          # Navigation styles
│   ├── footer.css          # Footer styles
│   ├── style-home.css      # Home page styles
│   ├── style-menu.css      # Menu page styles
│   ├── style-about.css     # About page styles
│   └── style-contact.css   # Contact page styles
├── js/
│   └── script.js           # Mobile menu toggle & scroll effects
├── images/                 # Food images & logos
└── videos/                 # Promotional videos
```

## 🎨 Pages

| Page | Description |
|------|-------------|
| **Home** | Hero section, new dish announcement, promotional video |
| **Menu** | 12 grilled specialties with prices |

| **Contact** | Address, phone, email, contact form, Google Maps |

## 🛠️ Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Flexbox, Grid, Animations, Media Queries
- **JavaScript** - DOM manipulation, scroll events
- **Font Awesome** - Social media icons
- **Google Fonts** - Roboto font family

## 📱 Responsive Breakpoints

- **Desktop**: > 1200px
- **Laptop**: 1000px - 1200px
- **Tablet**: 768px - 1000px
- **Mobile**: < 768px
- **Small Mobile**: < 450px

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/ahmedshawky10001-svg/Foodie-s.git
   ```

2. Open `pages/index.html` in your browser

3. Or use Live Server extension in VS Code

## 📝 Customization

- **Colors**: Edit CSS variables in each style file
- **Images**: Replace images in `/images/` folder
- **Menu Items**: Edit `Menu.html`
- **Contact Info**: Update `Contact.html`
